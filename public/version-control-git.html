Essential Git Workflow Cheat Sheets

Copy-ready commands for clean repositories and frictionless collaboration.

🌿

Clean Branch & Rebase Flow

Keep a linear, conflict-free commit history when collaborating on pull requests.

git checkout -b feature/search
# make changes & commit
git fetch origin main
git rebase origin/main
git push -u origin feature/search
🔄

Undo & Recovery Cheat Sheet

Safely roll back changes without losing your local working directory progress.

git stash save "WIP feature"
git stash pop
git reset --soft HEAD~1 # keep code
git restore --staged filename.js
🍒

Cherry-Pick & Bisecting

Port specific commit fixes across branches and locate regressions via binary search.

git cherry-pick <commit-hash>
git bisect start
git bisect bad
git bisect good <known-good-hash>
